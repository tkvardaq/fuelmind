Asking the station a question

Message the station's own WhatsApp from the number below and it answers from this PC — today's sales, credit, margin, the score. Send help to see the list. Nothing is opened to the internet and no other service is involved: the station is already connected to WhatsApp to send you the evening summary, and it listens on the same connection.

Only the number in Send to below is answered. A message from any other number is ignored, and you can see every question that was asked at the bottom of this page.
