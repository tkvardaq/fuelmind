Where your exports land

Point FuelMind at the folder your POS already writes to and you never have to copy a file again. Each export is read once, then moved into a processed folder beside it so you can always see what has been taken in.

Give the full path, starting from the drive letter. FuelMind checks that the folder exists and that it can write there before saving it, and tells you what is wrong if not.

Import a file now

For an export that is not in a watched folder — one on a USB stick, or sent to you by email. It goes through exactly the same checks as a file that arrives on its own.

If some rows cannot be read, the good ones are still imported and the rest come back to you as a file with a fuelmind_error column saying what was wrong. Fix those rows and import that file.

Enter a sale by hand

For when the POS is down or a pump was written up in the day book. A sale entered here is treated exactly like one from an export, so it counts towards revenue, margin, credit and your score in the same way.
